# Scanned models used in the workshop

Downloaded 6 Oct 2026 from Poly Haven (polyhaven.com) at 1k texture size, glTF format. Poly Haven assets are CC0 (public domain): free for any use,
no attribution required. They are kept here so the room can be rebuilt without the network.

| Folder | Poly Haven asset | Used as |
|---|---|---|
| `small_wooden_table_01` | Small Wooden Table 01 | Jesse's sewing table |
| `desk_lamp_arm_01` | Desk Lamp Arm 01 | The work lamp on his table |
| `wooden_stool_01` | Wooden Stool 01 | His seat |

No public-domain model of a sewing machine or of cotton reels was found (Poly Haven and the Smithsonian open 3D collection were searched), so
those are modelled by script in `jesse_workshop.py`.
